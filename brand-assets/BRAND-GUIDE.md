# Brand guide

## Core message
**Systems integrated. Value unlocked.**

The identity focuses on the solved problem and resulting value. Three disconnected system paths converge, become coherent, and produce one clear output.

## Palette
| Role | Hex | Website reference |
|---|---|---|
| Background | `#070B12` | approx. `oklch(9% 0.018 255)` |
| Foreground | `#E9EDF2` | approx. `oklch(92% 0.008 255)` |
| Cyan on dark | `#00CDD5` | approx. `oklch(72% 0.20 195)` |
| Ink on light | `#0B111B` | dark neutral |
| Cyan on light | `#009DA8` | contrast-adjusted accent |

## Typography
- Display/site name: Space Grotesk 700
- Technical labels/slogan: JetBrains Mono 400
- Fallbacks are embedded in the SVG styling.

## Recommended use
- Favicon/social avatar: mark
- Website header: wordmark
- Email footer: lockup at 320–640 px
- Invoice: light wordmark or light lockup
- Presentation/document cover: lockup
- When no symbol is wanted: text-only variant
