# tbsalling.dk brand assets

Outcome-led identity for Thomas Borg Salling — Senior Freelance Java Architect & Systems Integrator.

**Slogan:** Systems integrated. Value unlocked.

## Concept
Three fragmented inputs converge into one integrated path and a distinct output. The mark expresses integration as the means and unlocked value as the outcome.

## Included
- SVG masters: mark, site wordmark, logo + site + slogan, and site + slogan without logo
- Dark and light variants
- PNG exports for web, email signatures, invoices and documents
- Complete favicon set: SVG, ICO, 16/32 px, Apple touch icon, Android 192/512 px
- Social preview PNG
- Palette and usage guide

## Naming
- `dark`: use on dark backgrounds
- `light`: use on white or light backgrounds
- SVG and PNG files are transparent unless named `background-...`

## Clear space
Keep clear space around the mark equal to the diameter of its output dot. Do not stretch, recolor, rotate or add effects.
